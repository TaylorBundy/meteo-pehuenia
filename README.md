# Meteo Pehuenia

Página meteorológica estática orientada a Villa Pehuenia, excursiones 4x4 y montaña.

## Incluye

- Condiciones actuales.
- Temperatura y sensación térmica.
- Viento y ráfagas.
- Dirección del viento.
- Humedad y punto de rocío.
- Precipitación y probabilidad.
- Nieve.
- Nubosidad y visibilidad.
- Presión atmosférica.
- Amanecer y atardecer.
- Índice UV.
- Gráfico de las próximas 48 horas.
- Pronóstico horario.
- Pronóstico de 7 días.
- Búsqueda de localidades.
- Consulta por coordenadas.
- Evaluación meteorológica orientativa para una salida 4x4.

## API

Utiliza Open-Meteo y no requiere una clave API para el uso normal del endpoint público.

## Publicar en GitHub Pages

1. Subir `index.html`, `style.css` y `script.js` a un repositorio.
2. Abrir Settings > Pages.
3. En Source seleccionar la rama principal y `/root`.
4. Guardar.
5. GitHub publicará el sitio.

## Importante

La evaluación para excursiones es únicamente orientativa. Consultar siempre alertas oficiales, rutas, caminos, pasos fronterizos y condiciones reales del terreno antes de salir.
